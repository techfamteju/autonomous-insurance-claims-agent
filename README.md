# Autonomous Insurance Claims Processing Agent

This project implements a lightweight autonomous agent for processing FNOL documents.

## Features
- Field extraction
- Missing field detection
- Automated claim routing
- Explainable decisions

## Run
python src/fnol_agent.py

## Assignments

### Assignment 1: ACORD FNOL Processing
Basic processing of ACORD Automobile Loss Notice forms with
structured JSON output and validation.

📁 Folder: `assignment-1-acord-fnol`

### Assignment 2: Autonomous Insurance Claims Processing Agent
An extended autonomous agent that performs extraction,
validation, routing, and explainable decision-making.
