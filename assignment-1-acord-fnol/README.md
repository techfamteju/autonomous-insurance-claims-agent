
# ACORD Automobile Loss Notice – FNOL Processing

## Overview
This project demonstrates processing of an ACORD Automobile Loss Notice (FNOL) document.
The goal is to identify key insurance claim fields and represent them in a structured format.

## Input
- ACORD Automobile Loss Notice PDF

## Output
- Structured JSON with policy, loss, vehicle, and party details
- Identification of missing/critical fields

## Approach
1. Analyze ACORD form structure
2. Define structured schema
3. Extract and normalize fields
4. Validate mandatory information

## Tools
- Python
- PDF analysis (conceptual/manual for demo)
